\section*{5. 配位化学与电子结构}
\textit{下列为分问。}

\subsection*{5-1}
写出A、B、C、D、E、F、G和H的化学式。

\subsection*{5-2}
写出由E转变为F，F转变为G，G转变为H的离⼦⽅程式。

\subsection*{5-3}
A中的⾦属元素M可以形成 $\mathbf { M O } _ { 2 }$ 和 $\mathrm { Z n } { \bf M } _ { 2 } \mathrm { O } _ { 4 }$ ，它们均为磁性材料，⼴泛⽤于制作磁带和磁盘。分别写出$\mathbf { M O } _ { 2 }$ 和 $\mathrm { Z n { \bf M } _ { 2 } O _ { 4 } }$ 中M的价电⼦组态。

\subsection*{5-4}
A中的⾦属元素M可以形成不同形式的羰基化合物或者羰基阴离⼦，按照18电⼦规则画出

$\mathrm { N a _ { 2 } [ M _ { 2 } ( C O ) _ { 1 0 } ] }$ ]的阴离⼦结构，指出M的氧化态。
