\section*{1. 锰氧化物反应方程式}
\textit{下列为分问。}

\subsection*{1-1}
加热时，三氧化⼆锰与⼀氧化碳反应产⽣四氧化三锰。

\subsection*{1-2}
将 $\mathrm { K C N }$ 加⼊到过量的 $\mathrm { C u S O _ { 4 } }$ ⽔溶液中。

\subsection*{1-3}
在碱性溶液中， $\mathrm { { C r } _ { 2 } O _ { 3 } }$ 和 $\mathrm { K _ { 3 } F e ( C N ) _ { 6 } }$ 反应。

\subsection*{1-4}
在碱性条件下， $\mathrm { Z n ( C N ) _ { 4 } } ^ { 2 - }$ 和甲醛反应。

\subsection*{1-5}
$\mathrm { F e ( O H ) }$ _{2}在常温⽆氧条件下转化为 $\mathrm { F e _ { 3 } O _ { 4 c } }$

\subsection*{1-6}
将 $\mathrm { N a N O _ { 3 } }$ 粉末⼩⼼加到熔融的NaNH_{2}中，⽣成 $\mathrm { N a N _ { 3 } }$ （没有⽔⽣成）。
