\section*{1. 无机反应方程式书写}
\textit{下列为分问。}

\subsection*{1-1}
⼯业上⽤碳酸氢铵和镁硼⽯ $\mathrm { [ M g _ { 2 } B _ { 2 } O _ { 4 } ( O H ) _ { 2 } ] }$ 在⽔溶液中反应制备硼酸。

\subsection*{1-2}
从乏燃料提取钚元素的过程中，利⽤亚硝酸钠在强酸溶液中将 $\mathrm { P u ^ { 3 + } }$ +氧化为 $\mathrm { P u } ^ { 4 + }$ ，放出笑⽓。

\subsection*{1-3}
$\mathrm { N a B H _ { 4 } }$ 与氯化镍（摩尔⽐2:1）在⽔溶液中反应，可得到两种硼化物：硼化镍和硼酸（摩尔⽐1:3）。

\subsection*{1-4}
通过 $\mathrm { K M n O } _ { 4 }$ 和 $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ 在 $\mathrm { K F \mathrm { - H F } }$ 介质中反应获得化学法制 $\mathrm { F } _ { 2 }$ 的原料 $\mathrm { K _ { 2 } M n F _ { 6 \circ } }$

\subsection*{1-5}
磷化氢与甲醛的硫酸溶液反应，产物仅为硫酸鏻（盐）。
