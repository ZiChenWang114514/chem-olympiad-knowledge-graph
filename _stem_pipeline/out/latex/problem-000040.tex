\section*{10. 取代基影响反应产物}

\subsection*{10-1}
当 $\mathrm { R = C H _ { 3 } }$ 时，产物为A，分⼦式为 $\mathrm { C _ { 1 5 } H _ { 1 2 } O _ { 4 0 } }$ 研究表明 A 不含羟基，它的 1H NMR (CDCl_{3}, ppm): δ1.68 (3H), 2.73-2.88 (2H), 3.96-4.05 (2H), 5.57 (1H), 7.72-8.10 (4H)。画出 A 的结构简式。提⽰：δ不同，氢的化学环境不同。

\subsection*{10-2}
当 R = Ph 时，产物为 B，分⼦式为 $\mathrm { C _ { 2 0 } H _ { 1 4 } O _ { 4 \epsilon } }$ 。研究表明 B 含有⼀个羟基，它的 1H NMR (CDCl_{3}, ppm):δ 2.16 (1H), 3.79 (1H), 4.07 (1H), 5.87 (1H), 6.68 (1H), 7.41-7.77 (5H), 7.82-8.13 (4H)。画出 B 的结构简式；解释⽣成B的原因。

\subsection*{10-3}
