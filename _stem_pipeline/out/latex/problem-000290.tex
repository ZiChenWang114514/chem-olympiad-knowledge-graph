\section*{11. 磷化硼晶体结构}
\textit{下列为分问。}

\subsection*{11-1}
写出合成磷化硼的化学反应⽅程式。

\subsection*{11-2}
分别画出三溴化硼分⼦和三溴化磷分⼦的结构。

\subsection*{11-3}
磷化硼晶体中磷原⼦作⽴⽅最密堆积，硼原⼦填⼊四⾯体空隙中。画出磷化硼的正当晶胞⽰意图。

\subsection*{11-4}
已知磷化硼的晶胞参数 $\dot { a } = 4 7 8 \mathrm { p m }$ ，计算晶体中硼原⼦和磷原⼦的核间距。

\subsection*{11-5}
画出磷化硼正当晶胞沿着体对⻆线⽅向的投影（⽤实线圆圈表⽰P原⼦的投影，⽤虚线圆圈表⽰B原⼦的投影）。
